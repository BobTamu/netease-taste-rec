# 情境层口径（天气 / 假期 / 节气）

情境层决定推荐基调。三路信号缺一路就跳过并注明，**不臆造**。

## 一、天气

### 用脚本，不要手拼 URL

```bash
python scripts/weather.py "上海"
python scripts/weather.py "Tokyo" --json
python scripts/weather.py "朝阳" --pick 1
python scripts/weather.py --lat 31.2304 --lon 121.4737 --tz Asia/Shanghai
```

手拼 URL 有两个必踩的坑：
1. 接口吃经纬度，不吃城市名，得先地理编码；
2. `timezone` 写死会让「今天」和「深夜/清晨」整体错位几小时——日期一错，星期、假期倒计时、情境行全跟着错，而且**不会报错**。

### 地理编码必须双语 + 双排序

取 `results[0]` 是错的。两个实测案例：

**案例 1：`language=zh` 查 `New York`**
返回第一条是「约克 / 内布拉斯加州」，人口 7,864。纽约市（8,804,190）排在后面。直接取第一条会给出内布拉斯加的天气。

**案例 2：改成按人口排序，还是错**
`Melbourne` 在英格兰有个 793 人的小村。根因是中英双语查同一地点返回不同本地化名（`墨尔本` vs `Melbourne`），拿用户原始输入做精确匹配对真城市失效，反而让英文名的村庄拿了满分。

**正确做法**：中英各查一遍 → 按坐标合并 → **保留别名集合** → 按 `(是否精确同名, 人口, feature_code)` 三级排序。

`feature_code` 参考：`PPLC` 首都 > `PPLA` 一级行政中心 > `PPLA2` > `PPL`。

### 输出降噪

只在三种情况打印候选列表：
1. 非精确同名
2. 选中地点人口 < 50 万
3. 有竞争者人口 ≥ 选中项的 50%

干净的命中（如上海 2,487 万）不刷候选，避免每天输出噪音。

### WMO 天气码

| 码 | 含义 |
|---|---|
| 0 | 晴 |
| 1-3 | 大部晴朗 / 多云 / 阴 |
| 45-48 | 雾 / 雾凇 |
| 51-57 | 毛毛雨（含冻毛毛雨） |
| 61-67 | 雨（含冻雨） |
| 71-77 | 雪 |
| 80-82 | 阵雨 |
| 85-86 | 阵雪 |
| 95-99 | 雷雨（含冰雹） |

### 基调规则

| 条件 | 基调 |
|---|---|
| 降水（雨/雪/阵雨/雷雨）或湿度 ≥80% | 室内 · 低频 · 湿润感（城市夜景、雨、孤独但不丧） |
| 晴且日最高 25-33℃ | 轻快 · 明亮 · 公路 |
| 最低 <10℃ 或风速 ≥25km/h | 温暖厚实 · 低频贝斯 · 木吉他（叠加在上一条之上） |
| 以上都不满足 | 中性 · 留白 |

**信号都不强时明确输出「中性·留白」，不要硬凑基调。**

### 非中国城市

- **节气与中国法定节假日表只适用于中国**。脚本输出 `cn_holiday_table_applicable`，为 false 时不要套中国假期表，也不要拿节气当氛围标签。
- **南半球季节相反**。10 月是墨尔本的春天，标「秋末」就是错的。

### 接口不可用

跳过天气这一路，在输出里写明「天气接口不可用」。**不要用"大概"或往期数据顶替。**

## 二、假期临近度

判断顺序：

1. 法定节假日 ≤7 天 → 假期模式（松弛、旅行、公路、老歌怀旧）
2. 假期中 → 假期模式
3. 假期后 1-2 天 → 收心模式（舒缓、留白）
4. 周五晚 → 周末模式（放开、舞曲、摇滚）
5. 周日晚 → 收尾模式（舒缓、不刺激）

节假日表每年变动，**必须核对当年官方安排**，不要凭记忆写死日期。

### 已核实的 2026 年中国安排

来源：国办发明电〔2025〕7 号，gov.cn

| 假期 | 日期 | 调休上班 |
|---|---|---|
| 元旦 | 1/1–1/3 | 1/4 |
| 春节 | 2/15–2/23 | 2/14、2/28 |
| 清明 | 4/4–4/6 | — |
| 劳动节 | 5/1–5/5 | 5/9 |
| 端午 | 6/19–6/21 | — |
| 中秋 | 9/25–9/27 | — |
| 国庆 | 10/1–10/7 | 9/20、10/10 |

**2026 年 10 月下旬至 12 月无假期临近信号**，下一个待等的是 2027 元旦。这段时间情境基调交给天气与星期决定。

## 三、时间 / 节气

- 深夜 22 点后 → 安静、器乐、低 bpm
- 清晨 → 明亮、民谣
- 节气前后 3 天可作氛围标签（霜降→秋末、立冬→暖调）

节气标签**只在中国语境下使用**。
