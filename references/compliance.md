# 合规边界（对外复用前必读）

把本技能给别人用、或做成产品之前，先把三层分清楚。混在一起谈会得出错误结论。

## 第一层：抓取行为 → 违约，不是侵权

用私有 weapi 接口读公开歌单，违反的是网易云《用户协议》，属**合同违约**。后果是限流、封号，不是著作权赔偿。

二者性质完全不同：违约对应的是平台关系，侵权对应的是权利人。

## 第二层：歌单列表本身 → 基本不侵权

「歌名 + 歌手名」是**事实性信息**。《著作权法》保护表达、不保护事实与思想。几十首歌名的列表独创性极低，通常不构成作品。

这是本技能能存在的地基。只要输出停在「歌名 — 歌手」，风险接近于零。

## 第三层：真正的红线

| 行为 | 涉及权利 |
|---|---|
| 提供音频试听或下载 | 信息网络传播权（最严重） |
| 展示歌词全文 | 文字作品著作权 |
| 使用专辑封面图 | 美术 / 摄影作品著作权 |
| 商用 + 大规模抓取 | 《反不正当竞争法》（罚得比著作权更重） |

## 结论与红线

- 只输出「歌名 — 歌手」纯文本、个人自用 → 风险极低
- **技能不得扩展到音频、歌词、封面**
- 对外提供或收费前必须单独评估

## 另一条容易漏的

如果做成产品去收集**别人的歌单**，歌单一旦关联到可识别用户，就可能构成**个人信息**，受《个人信息保护法》约束，需要告知与同意。

「公开可见」不等于「可以随意收集和处理」。

## 对使用者的提示

本技能依赖未公开接口，属于非官方用法。使用者应知晓：
- 接口随时可能失效或被加强风控
- 高频调用可能触发账号处罚
- 不应将 cookie 或账号凭证写入脚本、日志或配置文件
